# NIRMAN AI — notebook snapshot frontend

Next.js frontend for the batch forecast export produced by `NIRMAN_AI_MVP_v7.ipynb`. It does not poll a backend or update in real time.

```bash
npm install
npm run dev
```

## Snapshot data

The current notebook export is bundled at `public/data/nirman_v7_project_risk.csv` and loads locally when a page needs data. It contains 125 ongoing projects from the supplied synthetic dataset. No backend polling is used.

To refresh it, run the notebook through the **Early-warning list** export cell (cell 12), then import the generated CSV from **Settings → Import notebook CSV**. The browser stores that replacement in local storage. The CSV must include `project_id`, `delay_6m`, `delay_12m`, `cost_overrun_6m`, and `cost_overrun_12m`.

## What the frontend shows

- Portfolio counts, risk bands, and an early-warning list.
- The four notebook probabilities: delay and cost-overrun risk at 6 and 12 months.
- Sector summaries, deadline context, project details, completeness, and CSV export.

The headline risk is the maximum of the four probabilities. The notebook's `pandas.cut` intervals are preserved: green through 30%, amber above 30% through 60%, and red above 60%.

The v7 notebook export does not provide new-project scoring, per-project SHAP explanations, historical risk trajectories, or arbitrary what-if scenarios. Those are not generated by this frontend. Its dataset and model outputs are synthetic and are not real-world evidence.
